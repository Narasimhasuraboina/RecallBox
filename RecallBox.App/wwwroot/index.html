RecallBox keeps its server in the background and never opens, focuses, searches, or scrolls WhatsApp. It can capture the currently visible chat, or import an official export for the available transcript and media.

Coverage is best effort. A background screen capture contains only what is already visible. Use a phone export ZIP for more history and media; neither method proves a complete account history.
