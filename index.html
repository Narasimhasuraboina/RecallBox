Supported formats and privacy details

WhatsApp: Android/iPhone text exports and ZIP exports with media. A ZIP may contain a chat transcript and its attachments.

Other chat exports: UTF-8 text transcripts with timestamped lines, JSON arrays or objects with a messages list, and CSV files with timestamp/date, sender/author, and message/text columns. A ZIP must include one of these transcript formats. Unsupported files are rejected; arbitrary ZIP contents are not guessed.

Local processing: the parser and ZIP library are included with this site. Your selected file is never sent to a server. The browser asks before writing to a selected folder. If direct folder writing is unavailable, RecallBox downloads one ZIP containing the same folder structure.

Limits: exports can omit older messages or media. Ambiguous dates are kept as original text and not guessed. RecallBox reports omitted attachments and parsing warnings in metadata.json.
